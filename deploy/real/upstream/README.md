# Official source references

`provenance.json` records the exact official source URLs and blob hashes inspected while preparing this integration. The referenced upstream files are not vendored here. Obtain the complete upstream release checkouts as described in `docs/REAL-SERVICES.md`; the private overlays are not standalone distributions.

Additional integrated reference: https://github.com/DIGI-UW/openelis-openmrs-hie/tree/027b6446fb4c5d8d0fd47058f041c503e286f038

That reference supplies OpenMRS/OpenELIS routing and example test-catalog metadata but contains older infrastructure and public default settings. Treat it as an isolated reference, not a public deployment template. Review upstream licensing and preserve required notices when installing or redistributing its components.
